## Missing baseline coverage (explicit gaps, task 3.1)

1. **Command-layer seams** (`tauri::State` commands are not callable without an app harness): create/update validation propagation incl. B3-1, password-on-update B3-2, SSH import port discard B3-3, delete's best-effort swallow. Pinned today at the store/keyring seams + code refs above; UI journeys covered later by E2E (Req 12.3).
2. **SSH config import end-to-end** from the real `~/.ssh/config`: fixed home path (Known Folder APIs ignore env overrides on Windows — task 2.3 finding); parser pinned at the `parse_ssh_config_content` seam instead.
3. **Real OS keyring round-trips** (Keychain / keyutils / Credential Manager): require OS daemons/hardware; the two pre-existing `#[ignore]`d tests in `store/credentials.rs` remain the opt-in path (`--run-ignored`); CI pins mapping logic via scripted builders.
4. **UI validation display** (1.1 "display a validation message"): form logic reviewed (audit); automated UI coverage belongs to task 3.4's domain (5.x) and E2E (12.3).

## Missing baseline coverage (explicit gaps, task 3.2)

5. **2.1 real-server TLS/NLA/CredSSP**: the connector sequence is audit-pinned only (client.rs L77–293); scripted `ConnectFn` outcomes and synthetic frames can never prove protocol behavior (Req 12.9 wording). Requires the real-server evidence gate (12.9 / task 3.5 interop baseline) before the protocol upgrade.
6. **Command-layer wrappers** `commands/session.rs` (`connect` duplicate limit check L26–33, `cancel_reconnect` L92–110 actor-gone error mapping, password retrieval from `CredentialStore`): same `tauri::State` harness gap as #1; the underlying `SessionManager`/actor logic those wrappers delegate to is pinned by the 2.2–2.5 rows.
7. **True concurrent admission race** (2.2 audit observation: check-then-insert around the async lock): not deterministically pinnable on a current-thread test runtime where `create_session` has no observable interleaving point; recorded as an audit note on the 2.2 row instead of a test.

## Missing baseline coverage (explicit gaps, task 3.3)

8. **Real-server input/resize/clipboard/screenshot evidence (Req 12.9)**: FastPath keyboard/mouse input on the wire, display-control resize negotiation with a live server, two-way plain-text clipboard sync, and screenshot real-content verification all require a real RDP server. The actor encode seams (3.1/3.2 rows) prove the client-side encoding only; mock frames and scripted transports never substitute (12.9 wording), exactly as gap #5 established for TLS/NLA. Cross-ref: task 3.5 interop baseline gates the upgrade on this evidence.
9. **Command-layer input wrappers** (`resize_session` 0/8192 validation `commands/session.rs` L176–198, `send_key_event`/`send_mouse_event`/`clipboard_write`/`clipboard_read` sender plumbing): same `tauri::State` harness gap as #1/#6. The actor-level equivalents (normalization, encoding, watch-channel clipboard) are pinned by the 3.1–3.5 rows; `useClipboard`-to-`clipboard_write` UI journeys belong to E2E (12.3).
10. **React wiring of the input/display controls**: the in-component resize-debounce wiring, window-level key capture (`preventDefault`, INPUT/TEXTAREA/SELECT bypass in SessionCanvas), rAF mouse-move coalescing, the `useClipboard` paste/shortcut double-sync (a real paste fires both the `paste` event and the Ctrl/Cmd+V shortcut path, issuing two `clipboard_write` calls with the same text), absence of modifier-release synthesis on blur, and the DOM screenshot path (first-canvas selection, `toDataURL` download) all require a component/hook test environment (jsdom/testing-library) that this repo does not have. 11. **Mock sessions never forward input** (pinned by `test_mock_session_accepts_input_commands_without_frames_or_disconnect`): the mock frame loop accepts key/mouse/clipboard commands and drops them (the TODO zone deferred from task 3.2).
